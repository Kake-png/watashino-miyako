# 検索条件と15駅の再監査

更新日: 2026-09-22

## 方針

- 感覚語だけで決まる条件は置かない。
- 徒歩・自転車・車の時間、施設規模、乗換回数、営業時間のいずれかで判定する。
- 「静かな住宅地」「夜もにぎわう」「大学が近い」「車で出かけやすい」「散歩向き」は独立条件から外した。
- 散歩は「大きな公園」「川・河原」「海・港」「まとまった商店街」のいずれかから探す。
- 家賃は重複するタグではなく、駅ごとの1K平均値を上限で絞る。

## 条件

| 選択肢 | 掲載条件 |
|---|---|
| 複数路線 | 同じ駅、または徒歩10分以内の別駅から2路線以上を使える |
| 羽田へ直通 | 羽田空港まで乗換なしの列車、または直行バスがある |

## 実装上の注意

- 条件同士は初期状態でAND検索。「どれか満たす」に切り替えるとOR検索。
- 求める生活のプリセットは、そのテーマに属する具体条件のOR検索。
- 家賃上限はタグ検索の後に必ずANDで適用する。
- 店舗・交通・家賃相場は変動するため、駅追加前に全件を同じ基準日で再確認する。
