# 駅ページ調査プロンプト

Gemini / Claudeなどへ渡すときは、`{駅名}`、`{自治体}`、`{都道府県}`を置き換える。1回につき1〜3駅までにし、出力を人が確認してから `public/assets/data.js` へ反映する。

## プロンプト本文

あなたは「物件ではなく、駅と街の特色から住む場所を探すサイト」の調査担当です。対象は **{都道府県}{自治体}の{駅名}駅** です。

目的は住みやすさランキングを作ることではありません。駅前から徒歩約12分までの街の変化、日常生活の組み立て方、強みと交換条件を、出典付きで整理してください。

### 必須ルール

1. Web検索を行い、変化し得る事実にはURL、ページ名、公開主体、確認日を付ける。
2. 鉄道事業者、自治体、国・都道府県、施設公式などの一次情報を優先する。
3. 推測と確認済み事実を混ぜない。「現地確認が必要」は明記する。
4. 治安を主観で断定しない。使える公的統計の集計単位を示し、駅単位に無理に換算しない。
5. 家賃、駐車場、店舗数は取得時点・対象範囲・集計方法が明確な場合だけ数値化する。単一の募集事例を相場と呼ばない。
6. 「おすすめ」「穴場」「住みやすさ○点」などのランキング表現は使わない。
7. 再開発、工事、運行、店舗は将来変わるので、基準日を必ず付ける。
8. 写真候補はWikimedia Commonsのファイルページのみ挙げる。CC0、CC BY、CC BY-SAのうち、作者・版・ライセンスURLを確認できるものに限る。Google画像検索、SNS転載、Street Viewの画面保存は不可。

### 調べる内容

- 路線、主な接続方向、乗換時の駅内・地上移動
- 駅の出口・線路・川・幹線道路・坂による街の分かれ方
- 徒歩0〜3分、3〜7分、7〜12分の街の変化
- スーパー、商店街、日用品、外食、本・文化施設
- 公園、河川敷、海辺、散歩道、自転車でつながる場所
- 車の主要動線、高速道路入口方面、駅前道路の制約
- 夜の店、人通り、帰宅経路で確認すべきこと
- 空港、新幹線、大きな公園、競馬場など特徴的な目的地へのつながり
- 平日と休日、昼と夜の違い
- 再開発や大規模工事
- 住居費を比較するときに差が出る要因（駅距離、方角、築年数等）

### 出力形式

最初に「確認済み事実」と「編集要約」を分けて書き、その後に次のJSONをコードブロックで出してください。分からない項目を創作せず `null` または空配列にしてください。

```json
{
  "slug": "romanized-slug",
  "name": "駅名",
  "kana": "よみ",
  "area": "自治体名",
  "lines": [],
  "descriptor": "30字程度の街の骨格",
  "summary": "120〜180字の編集要約",
  "strengths": [],
  "cautions": [],
  "walk": [
    ["0–3分", "短い見出し", "説明"],
    ["3–7分", "短い見出し", "説明"],
    ["7–12分", "短い見出し", "説明"]
  ],
  "notes": {
    "transport": "",
    "daily": "",
    "atmosphere": "",
    "weekend": ""
  },
  "practical": {
    "cost": "",
    "car": "",
    "outdoors": "",
    "evening": ""
  },
  "suggestedTags": [],
  "photoCandidates": [
    {
      "commonsFilePage": "https://commons.wikimedia.org/wiki/File:...",
      "scene": "駅前・商店街・住宅地など",
      "author": "",
      "license": "",
      "licenseUrl": "",
      "date": ""
    }
  ],
  "sources": [
    {
      "claim": "この出典が支える事実",
      "publisher": "",
      "title": "",
      "url": "",
      "checkedAt": "YYYY-MM-DD",
      "sourceType": "official|public-data|secondary"
    }
  ],
  "needsFieldCheck": []
}
```

最後に、公開前に人間が現地または一次情報で再確認すべき項目を5件以内で列挙してください。

## 反映前の人間チェック

- URLを実際に開き、記述と一致するか
- 写真のファイルページに作者・ライセンス・元画像が揃うか
- 駅単位で断定できない治安・災害・相場表現がないか
- 方向差と徒歩圏が、地図上の実際の道路・線路・河川と矛盾しないか
- `npm run build && npm run check` が成功するか
